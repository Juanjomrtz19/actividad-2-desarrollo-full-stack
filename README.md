# REST API Design for Book Catalog

| Http Method | Endpoint | Query Params                                                                  | Request JSON Body (Payload) | Response JSON Body                                                                                                                                                                                        | Possible HTTP Response Codes |
|:------------| :--- |:------------------------------------------------------------------------------| :--- |:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------| :--- |
| POST        | `/books` |                                                                               | `{"title": "string", "author": "string", "publication_date": "string", "category": "string", "isbn_code": "string", "visibility": boolean, "valoration": "integer"}` | `{"id": "integer", "title": "string", "author": "string", "publication_date": "string", "category": "string", "isbn_code": "string", "visibility": boolean, "valoration": "integer", "stock": "integer"}` | 201 Created,<br>400 Bad Request |
| GET         | `/books/{bookId}` |                                                                               | | `{"id": "integer", "title": "string", "author": "string", "publication_date": "string", "category": "string", "isbn_code": "string", "visibility": boolean, "valoration": "integer"}`                     | 200 OK,<br>404 Not Found |
| PUT         | `/books/{bookId}` |                                                                               | `{"title": "string", "author": "string", "publication_date": "string", "category": "string", "isbn_code": "string", "visibility": boolean, "valoration": "integer"}` | `{"id": "integer", "title": "string", "author": "string", "publication_date": "string", "category": "string", "isbn_code": "string", "visibility": boolean, "valoration": "integer", "stock": "integer"}` | 200 OK,<br>400 Bad Request,<br>404 Not Found |
| PATCH       | `/books/{bookId}` |                                                                               | **Partial update** (any attribute combination) | `{"id": "integer", "title": "string", "author": "string", "publication_date": "string", "category": "string", "isbn_code": "string", "visibility": boolean, "valoration": "integer", "stock": "integer"}` | 200 OK,<br>400 Bad Request,<br>404 Not Found |
| DELETE      | `/books/{bookId}` |                                                                               | | `{"message": "Book deleted successfully"}`                                                                                                                                                                | 200 OK,<br>404 Not Found |
| GET         | `/books` | title, author, publication_date, category, isbn_code, valoration, visibility. | | `[{"id": "integer", "title": "string", "author": "string", "publication_date": "string", "category": "string", "isbn_code": "string", "visibility": boolean, "valoration": "integer", "stock": "integer"}]`                 | 200 OK,<br>404 Not Found |

> **Note on Update Methods**:
> * **PUT**: Replaces the entire resource. All required fields must be sent.
> * **PATCH**: Supports **partial updates**. You can send any combination of attributes (e.g., just the `title`).
